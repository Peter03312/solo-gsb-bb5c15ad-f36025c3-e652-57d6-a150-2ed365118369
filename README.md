# 陶片拼接推演 Web 工作台

供考古工作室在浏览器中推演陶片拼合的工具：上传陶片照片、逐片标定毫米比例尺，
记录“一片局部坐标到另一片”的旋转 / 平移刚体映射与接缝说明；画布按**已采纳**接缝
把陶片拼为若干连通组，显示每片位置及其所依据的接缝链。

## 功能要点

- **照片与毫米比例尺**：上传时在图上点选比例尺两端并填写真实毫米数，
  每片独立标定 `mm/px`；未标定的陶片不能作为接缝端点。
- **接缝（局部坐标映射）**：记录 `B 局部点 = 旋转(A 局部点) + 平移(mm)`
  及接缝说明；状态分为 `adopted`（采纳，参与拼合）、`proposed`（仅记录）、`rejected`（被环校验拒绝）。
- **连通组画布**：每片位置由连通组锚点出发的接缝链唯一推算（BFS 刚体变换复合）；
  未连通陶片单独成面板显示。
- **环闭合校验**：新接缝两端若已连通即形成环，比较现有链与新接缝推出的位置偏差，
  偏差超过方案设定的毫米容差时**拒绝采纳、指出冲突接缝链、保持原布局**
  （拒绝记录含冲突链与闭合差，可在界面查看后清除）。
- **撤销接缝**：删除接缝后连通组与位置全部从头重算，不沿用失效布局；
  删除陶片会级联删除相关接缝。
- **多人编辑保护**：每个方案带乐观锁版本号，所有写操作必须携带
  `X-Expected-Version`；版本不符返回 `409`，前端弹出版本冲突提示并要求刷新，
  不会静默覆盖。页面每 5 秒轮询一次，发现他人更新会自动载入最新布局。
- 画布按真实毫米比例绘制，每个连通组带毫米比例尺；点选陶片可查看
  “锚点 → 该片”的完整接缝链，输入新接缝参数时实时显示虚线预览与闭合差。

## 技术栈

- Node.js 20 + Express（REST API）
- SQLite（`better-sqlite3`，WAL 模式，外键级联）
- 原生浏览器 Canvas 2D，无前端构建步骤
- 几何核心（矩阵复合、连通组布局、环闭合差）由前后端**共用同一份**
  [`shared/geometry.js`](shared/geometry.js)，保证显示与校验一致

## 方式一：Docker Compose（推荐）

```bash
docker compose up -d --build
```

打开浏览器访问：

```
http://localhost:8080
```

首次启动时容器会自动在数据卷中创建 SQLite 数据库并执行全部建表语句，无需手工初始化。
上传的照片与数据库保存在命名卷 `workbench-data`（容器内 `/data`）。

停止 / 查看日志：

```bash
docker compose down
docker compose logs -f
```

若构建环境无法访问 GitHub 下载 `better-sqlite3` 预编译二进制，可指定镜像源构建：

```bash
docker build -t potsherd-workbench \
  --build-arg PREBUILT_MIRROR=https://registry.npmmirror.com/-/binary .
```

## 方式二：直接用 Node 运行

需要 Node.js ≥ 20。

```bash
npm install
npm start
```

默认访问 http://localhost:8080 ，数据写入项目下的 `./data/`（自动创建、自动建表）。

也可以运行几何核心自测：

```bash
npm test
```

## 可配置项（环境变量）

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `PORT` | `8080` | 容器/服务监听端口 |
| `HOST_PORT` | `8080` | Compose 映射到宿主机的端口，例如 `HOST_PORT=9090 docker compose up -d` |
| `DATA_DIR` | Docker 中 `/data`，本地 `./data` | SQLite 数据库文件（`workbench.db`）与上传图片（`uploads/`）目录 |
| `MAX_UPLOAD_MB` | `20` | 单张陶片照片上传大小上限 |

每个方案各自的**环闭合毫米容差**在“方案设置”中配置（默认 2.0 mm，可随时修改）。

## 网页访问端口

- `8080`（默认）：Web 界面与 API
  - `/index.html` 方案列表 / 新建
  - `/project.html?id=<方案ID>` 拼接工作台
  - `/api/...` REST API
  - `/uploads/...` 陶片照片

## 使用流程

1. 在首页创建方案并设定环闭合容差（毫米）。
2. 进入方案，点“上传陶片照片并标定比例尺”：选图 → 在比例尺两端各点一下 →
   填写该线段的毫米数 → 上传。重复直到所有陶片就位。
3. 在右栏选择 A、B 两片，输入旋转（度，逆时针为正）与平移（毫米），
   画布上会以虚线预览 B 片位置；填写接缝说明后点“采纳接缝”。
   - 若两片此前未连通：直接合并为一个连通组；
   - 若已连通形成环：界面实时显示闭合位置差与旋转差；
     超差时提交会被服务端拒绝（422），右侧列出冲突链，布局不变；
     容差内的一致接缝会被采纳为冗余约束。
4. 在画布点选陶片，右栏显示该位置所依据的接缝链；点选接缝可高亮其连线。
5. 接缝可随时“撤销”，连通组和各片位置立即重算；“仅记录”的接缝不参与布局，可随后采纳。
